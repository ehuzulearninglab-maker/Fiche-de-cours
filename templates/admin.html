Utilisateurs inscrits

Liste de tous les comptes Supabase (admins et utilisateurs simples). Le badge Admin indique les comptes administrateurs. Vous pouvez promouvoir un utilisateur en admin, retirer le rôle d'un autre admin, suspendre l'accès (le compte est conservé) ou supprimer définitivement (cascade : profil + conversations + messages). Vous ne pouvez ni modifier votre propre rôle ni vous supprimer vous-même. La colonne Tokens donne le total de jetons LLM consommés par chaque utilisateur (toutes les requêtes IA confondues).
